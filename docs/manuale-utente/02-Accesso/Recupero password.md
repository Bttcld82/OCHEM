# Recupero password

> [!note] Funzionalita' in sviluppo
> Al momento il recupero password self-service non e' ancora implementato.

## Come procedere

Se hai dimenticato la password, contatta un **amministratore** della piattaforma che potra':
- Resettare la tua password manualmente
- Generare un nuovo **invito** con link per reimpostare le credenziali
