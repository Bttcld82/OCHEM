# Ruolo Admin

L'**Admin** e' il ruolo con il massimo livello di accesso sulla piattaforma.

## Permessi

| Azione | Consentita |
|--------|-----------|
| Accesso a qualsiasi laboratorio | Si |
| Accesso al [[07-Admin/Dashboard admin\|Pannello Admin]] | Si |
| Creare e gestire laboratori | Si |
| Creare e pubblicare cicli PT | Si |
| Gestire parametri, unita', tecniche | Si |
| Approvare/rifiutare registrazioni | Si |
| Gestire utenti e ruoli globalmente | Si |
| Promuovere/rimuovere altri admin | Si |

## Vincoli di sicurezza

> [!warning] Ultimo Admin
> Deve esserci sempre almeno **un Admin** nel sistema. Il sistema impedisce di rimuovere il privilegio admin all'ultimo amministratore rimasto.

## Come si diventa Admin

- Il primo admin viene creato in fase di setup del sistema
- Un admin esistente puo' promuovere altri utenti ad admin dal pannello [[07-Admin/Gestione utenti|Gestione utenti]]
