# Ruolo Viewer

Il **Viewer** e' il ruolo base per laboratorio. Ha accesso in **sola lettura**.

## Permessi

| Azione | Consentita |
|--------|-----------|
| Visualizzare la dashboard | Si |
| Accedere all'hub del laboratorio | Si |
| Vedere i cicli pubblicati | Si |
| Consultare la tabella risultati | Si |
| Visualizzare le carte di controllo | Si |
| Caricare risultati (upload CSV) | **No** |
| Gestire utenti del laboratorio | **No** |

## Quando viene assegnato

- Quando un admin invita un utente con ruolo "viewer"
- Quando un owner del laboratorio aggiunge un collaboratore in sola lettura
