# Ruolo Analyst

L'**Analyst** e' il ruolo operativo del laboratorio. Puo' caricare dati e consultare risultati.

## Permessi

| Azione | Consentita |
|--------|-----------|
| Tutto cio' che fa un [[Ruolo Viewer\|Viewer]] | Si |
| Scaricare il template CSV | Si |
| Caricare risultati (upload CSV) | Si |
| Visualizzare calcoli z-score | Si |
| Gestire utenti del laboratorio | **No** |

## Quando viene assegnato

- Quando un admin o owner invita un operatore di laboratorio
- Per utenti che devono caricare attivamente i risultati delle analisi
