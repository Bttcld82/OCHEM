# Dashboard admin

La dashboard amministrativa offre una panoramica globale della piattaforma.

**URL:** `/admin/dashboard`

## Accesso
Riservato agli utenti con ruolo **Admin** (`@role_required('admin')`).

## Statistiche mostrate

| Indicatore | Descrizione |
|------------|-------------|
| **Laboratori totali** | Numero di laboratori registrati |
| **Cicli totali** | Numero di cicli PT nel sistema |
| **Documenti** | Numero di documenti caricati |
| **Cicli in attesa** | Cicli in stato `draft` da revisionare |
