# Hub Laboratorio

L'Hub Laboratorio e' la **pagina centrale** di ogni laboratorio. Fornisce una panoramica rapida e link diretti alle funzionalita'.

**URL:** `/l/<lab_code>`

## Layout

L'hub e' organizzato in **tre card** informative:

### Card Cicli
Mostra gli ultimi **5 cicli pubblicati** a cui il laboratorio partecipa:
- Nome del ciclo
- Provider
- Stato
- Date di inizio/fine

### Card Upload
Mostra gli ultimi **10 upload** effettuati dal laboratorio:
- Nome file originale
- Data di upload
- Stato (pending, processed)
- Utente che ha caricato

### Card QC (Quality Control)
Mostra i parametri attivi e un riepilogo della qualita':
- Parametri monitorati
- Link rapido alle [[06-Statistiche/Carte di controllo|Carte di controllo]]

## Navigazione dall'Hub

Dall'hub puoi accedere a:
- [[06-Statistiche/Caricare i risultati|Upload risultati]] (se sei almeno Analyst)
- [[06-Statistiche/Tabella risultati|Tabella risultati]]
- [[06-Statistiche/Carte di controllo|Carte di controllo]]

- Richiede: login + disclaimer
- Ruolo minimo per laboratorio: `viewer`
