# Dashboard utente

La Dashboard e' la **pagina principale** dopo il login. Mostra una panoramica di tutti i laboratori a cui sei associato.

**URL:** `/dashboard`

## Cosa vedi

Una tabella con i tuoi laboratori:

| Colonna | Descrizione |
|---------|-------------|
| Laboratorio | Nome del laboratorio |
| Codice | Codice identificativo (es. `LAB_ALPHA`) |
| Citta' | Sede del laboratorio |
| Ruolo | Il tuo ruolo in quel laboratorio |
| Azione | Link **"Apri hub"** per accedere al laboratorio |

## Come usarla

1. Dopo il login, atterri automaticamente sulla Dashboard
2. Individua il laboratorio su cui vuoi lavorare
3. Clicca su **"Apri hub"** per accedere all'[[Hub Laboratorio]]

> [!tip] Piu' laboratori
> Se sei associato a piu' laboratori, li vedrai tutti elencati, ciascuno con il rispettivo ruolo. Puoi avere ruoli diversi in lab diversi.

## Accesso

- Richiede: [[02-Accesso/Login|Login]] + [[02-Accesso/Disclaimer|Disclaimer]] accettato
- Ruolo minimo: qualsiasi (viewer, analyst, owner_lab)
